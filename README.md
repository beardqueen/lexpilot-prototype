# LexPilot Prototype

企业 AI 法务知识库与合同审查平台高保真原型。

## 功能范围

- 角色权限：业务 / 法务
- 合同智能审查
- 企业法律知识库
- AI 法律问答
- 审批协同
- 风险看板

## 本地预览

```bash
node server.js
```

打开：

```text
http://127.0.0.1:5173
```
